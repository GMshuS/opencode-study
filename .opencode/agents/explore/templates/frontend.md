# 输出定义

> 加载后即提示词的一部分，说明文字不写入产物。本文件分「输出格式定义」与「约束与要求」两大块；本文件 frontmatter 与第一块的字段集、章节规则、产物骨架共同构成完整输出格式定义。

## 一、输出格式定义

### frontmatter 字段集

| 字段 | 必填 | 约束 |
|---|:---:|---|
| `schema` | 是 | `explore-note/v1` |
| `date` | 是 | `YYYY-MM-DD`，与文件名中的日期一致 |
| `topic` | 是 | kebab-case，与文件名中的 slug 一致 |
| `template` | 是 | `frontend@2.0`，必须指向真实存在的本模板文件 |
| `template_selection` | 是 | 固定 `用户确认`（模板由用户选定） |
| `status` | 是 | `已确认` / `待补充`；缺项时标 `待补充` 并回显，不拒写 |
| `source` | 是 | `用户确认` / `待用户确认` |
| `revision` | 否 | 默认 1；有修正记录时递增 |
| `updated` | 否 | `YYYY-MM-DD`，最近一次修订日期 |
| `downstream` | 否 | 交接目标标识，可省略 |

```yaml
---
schema: explore-note/v1
date: 2026-09-16
topic: auth-refactor
template: frontend@2.0
template_selection: 用户确认
status: 已确认
source: 用户确认
revision: 1
---
```

### 章节集合与规则

| 章节（H2） | 规则 | 内容要点 |
|---|:---:|---|
| `## 背景与问题` | 必填 | 现状 / Context、目标、非目标；现有页面结构、状态归属与体验问题 |
| `## 关键决策与方案` | 必填 | 技术选型及依据、已选方案或 A/B/C 对比、备选与否决理由、决策后果 |
| `## 待办与遗留` | 必填 | 开放问题 / 待验证项 / 实现任务（checkbox） |
| `## 总体设计` | 条件必填 | 涉及改动时必填（页面与组件树 / 总流程 / 状态归属 / 设计规范）；纯调研可省略 |
| `## 详细设计` | 条件必填 | 涉及改动时必填（组件职责 / 状态流 / 交互与异常态 / UI 兼容）；纯调研可省略 |
| `## 风险与约束` | 可省略 | 兼容 / 性能 / 视觉一致性 + 非功能性 checklist |
| `## 测试建议` | 条件必填 | 涉及改动时必填（交互与异常态 / 视觉回归 / 兼容矩阵）；纯调研可省略 |
| `## 修正记录` | 条件必填 | `revision = 1` 整章省略；`revision ≥ 2` 必填且写明变更来源，位置固定在文末（附录之前） |

## 二、约束与要求

### 内容保真

- 只记录用户明确认可的结论；未验证判断标 `[假设]` / `[待验证]`，不得写成已决事项。
- 每条注明来源（`用户确认` / `待用户确认`）；已核实项附文件位置。

### 填写要求

- 本模板按前端改造场景收紧章节：涉及改动时 `## 总体设计` / `## 详细设计` / `## 测试建议` 不可省；纯调研可省略。
- 章节级占位：每章写 `> 填写指引` / `> 允许形态` / `{内容}`；不涉及写「不适用」或整章删除，不留半填充占位。
- `## 关键决策与方案` 只记「选了什么 / 为什么 / 备选」；组件树、总流程、状态流一律放 `## 总体设计`。
- `## 详细设计` 须覆盖交互与异常态、灰度·回滚（涉及改动时）。
- `## 待办与遗留` 是实现任务，`## 测试建议` 是给测试策略的输入；方案论证用的「场景验证矩阵」不属于测试建议。
- **本模板可自由增删章节与字段**；调整时同步「章节集合与规则」表与「产物骨架」即可，不必改 agent 定义。

### 落笔前自检

写入前逐项核对并回显，缺项标「待补充」，**不拒写、不新增门禁**：

1. 文件名中的日期 / slug ↔ `date` / `topic` 一致
2. frontmatter 必填字段齐全；`template` 指向真实文件；`template_selection = 用户确认`
3. 必填三章存在；涉及改动时 `## 总体设计` / `## 详细设计` / `## 测试建议` 存在；`revision ≥ 2` 时 `## 修正记录` 存在且写明变更来源
4. `## 详细设计` 覆盖交互与异常态、灰度·回滚（涉及改动时）
5. 状态标注与来源标注齐全；无半填充骨架占位（`{内容}` 已全部替换或整章删除）
