# 模型基线快照（按需加载）

> 本表不是权威，也不替代 §3 的查证纪律：输出参数时仍按「用户给定 > 官方文档当前值 > 平台不暴露 / 未公布」取值，**不得凭记忆填数值**。平台版本不在表内时，走 §3 第 2 / 3 条，不套用最接近的变体行。
> 数值口径：`〔官①-④〕` 官方可查（依据见 §C）、`〔经验〕` 调优区间（输出时标注「经验值，以实际平台为准」）、`〔平台〕` 不暴露 / 未公布 / 按版本核对（不填数值）。

> - `〔官〕` 为官方默认值或不得超出的硬边界，不得改写成区间；`〔经验〕` 写成调优区间；`〔平台〕` 按字面输出，不填数值。
> - **变体不混用**：蒸馏 / Turbo 变体 CFG 恒为 1.0，负向词按 `SKILL.md` §3 处理，不套用同模型标准版的 CFG 与步数。
> - prompt 上限是硬边界，不是配额或质量目标；单位用 token / 字符，不用汉字或词数。`$REF_CONSTRAINT` 与 `$MODEL_GUARD` 计入其中。
> - 帧数 / fps / 分辨率按平台默认值填写，不写进提示词。长视频分段拼接时长 ≤5s、拼接处光影色调对齐；支持原生长时长 / 多镜头的版本不套用此规则。
> - 低分辨率 + 人脸占画面 <1/10 易人脸融化：裁近主体或缩短帧数；运动幅度越大越易闪烁，先降幅度再改提示词。

## C. `〔官〕` 依据（公开文档 / 官方仓库可查，改表时按此复核）

1. **Wan2.1 / 2.2**：官方 `generate.py` 默认 T2V 50 步 / I2V 40 步、`guide_scale 5.0`、`frame_num 81`、`sample_shift 5.0`；umt5 文本编码器默认 `text_len 512`（可调大），2.2 的 T5-XXL context 为 512 token。
2. **LTX-Video**：官方仓库 / diffusers 文档——0.9.7 蒸馏版 `guidance_scale = 1.0` 且 4-10 步 + 自定义 timesteps；标准版 `guidance_scale 3-3.5` + STG；T5-XXL 默认 128 token 可调至 512；2.3 为 T5 256 + Gemma 512 双编码器；2.5 起原生多镜头与同步音视频；0.9.5+ 支持多条件图 / 视频插值。
3. **MiniMax 海螺 API 文档**：prompt ≤2000 字符（中英文）、duration 6 / 10（1080P 仅 6s）、运镜 `[指令]` 语法、首帧 / 首尾帧图生视频接口。
4. **HunyuanVideo / diffusers**：固定 129 帧（4k+1）、`num_inference_steps` 默认 50、LLaMA + CLIP 双文本编码器。

> 本文件不含负面词包与模型防护句：这类通用词由模型按 `SKILL.md` §3 的取用原则即时生成，不固化成表。
