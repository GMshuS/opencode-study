---
name: prompt-generator-novelview
description: 当用户需要基于当前图片里人物或物体的现有状态，生成正面、侧面、背面等不同观察视角的图片提示词时调用。每个视角各产出一条独立的中英提示词，附参考图绑定、状态保持与跨视角一致性约束、模型与参数建议。
---

## 1. 定位与边界

处理的是**保持当前状态、只换观察视角**：参考图里的人物 / 物体处于某个具体姿态、动作或摆放状态，需要产出从其它角度观察同一状态的画面。

- **必须有当前图**；无参考图时不臆测，追问或说明本技能不适用。
- 每个视角**各出一条独立提示词**，每条单独生成一张图；不拼成一张多格画面，不分栏排版。
- 本技能只做文本编排：不读取图片文件，参考图由出图平台接收，提示词里只用文字引用。

> 与「换风格 / 换背景」类需求的区别：这里要改的只是**观察角度**；主体的姿态、状态、服饰、外观，以及场景与背景都延续原图，不换成纯色或简洁背景。

## 2. 视角集

视角由**两个正交维度**组成，每条提示词各取一个值组合：

**水平方位**（决定主体哪一面朝向镜头，也主要决定哪些特征可见）

| 方位 | 中文措辞 | English |
|---|---|---|
| 正面 | `正面视角` | `front view` |
| 3/4 侧面 | `四分之三侧面视角` | `three-quarter view` |
| 侧面 | `侧面视角，90度侧视` | `side view, 90 degree profile` |
| 背面 | `背面视角` | `back view` |

**俯仰角**（与水平方位正交，可叠加）

| 俯仰 | 中文措辞 | English |
|---|---|---|
| 平视（默认） | `平视` | `eye level` |
| 俯视 | `俯视` | `high angle view` |
| 仰视 | `仰视` | `low angle view` |
| 顶视 | `顶视` | `top-down view` |

> - 每条提示词 = 一个水平方位 + 一个俯仰角，如 `背面视角，俯视` / `back view, high angle`；平视可省略。
> - 一次只写**一组**，不并列多个角度；默认视角集仍为 正面 / 侧面 / 背面（均按平视）。

**可见性原则**：状态保持项只写**当前视角实际可见**的特征；不可见的特征直接省略，不写「保持」。
跨视角恒定的只有身份锚点、服饰配色与姿态状态；表情、五官、正面 / 背面细节属于视角相关的可见特征，按本次的水平方位与俯仰角自行判断，不逐条复制、不套固定映射表。

## 3. 每条提示词的结构（顺序固定）

1. **参考图绑定**：锁定主体身份、外观与状态，如 `以参考图中的{主体类别词}为准，`
2. **状态保持项**：写该视角**实际可见**的当前姿态、动作、服饰与材质特征（按 §2 可见性原则）；不可见的特征直接省略，不写「保持」
3. **视角指令**：取自 §2 的一组**水平方位 + 俯仰角**措辞（一次只写一组），放在本段靠前
4. **一致性约束**：主体身份与服饰跨视角统一、场景与背景延续原图、光影方向随视角合理变化

组装为：`绑定句 + 状态保持短语 + 视角短语 + 一致性短语`，段内逗号、段间分号（`；` / `; `），中英一一对应、单句不混排，句尾不加分号。

中英对照示例（背面）：

```text
以参考图1中的人物为准，双臂交叉站立，米白色针织衫，深色长发及肩；背面视角，平视；主体身份与服饰配色与参考图一致，场景与背景延续原图，光影方向随视角自然调整
based on the person in reference image 1, arms crossed, cream knit sweater, dark shoulder-length hair; back view, eye level; identity and outfit colors consistent with the reference image, scene and background continuing the reference image, light direction adjusted naturally to the new viewpoint
```

**禁止**写「保留原图相机视角 / 保持构图不变」这类锚点——本任务要改变的正是观察角度；也**禁止**写「纯色背景 / 简洁背景」——背景同样延续原图。
**不写朝向词**：主体朝向由姿态状态隐含，每条只写 §2 的一组方位 + 俯仰措辞；「朝向不变、变化的是相机方位」只在 `tips` 声明一次。

## 4. 跨视角一致性

- 主体身份锚点、服饰、配色、姿态状态在**都可见**的视角条目里用同一套词，不换同义词；不可见特征按 §2 可见性原则处理，不逐条复制。
- 全局一致性约束只在 `tips` 与「🎯 跨视角一致性」小节声明一次，**不逐条重复**。
- 朝向：主体自身朝向不变，变化的是相机方位；该解释只在 `tips` 声明，不写进任何一条提示词，也不写朝向词。
- 光线：光源方向相对环境保持合理，但投影与明暗随视角变化属正常，不要写成「光影完全不变」。
- 场景与背景：延续原图的环境、背景元素与色调，不改成纯色 / 简洁背景；但可见范围与透视随视角自然变化，不要写成「背景完全不变」。
- 明确不要的元素移入负面词，不写进绑定句。

## 5. 负面词（直接取用）

- 中文：`身份漂移，姿态改变，服装变化，多余主体，视角混淆，镜像翻转，结构变形，画风跳变，背景被替换，色调跳变，文字，水印`
- English: `identity drift, changed pose, changed outfit, extra subjects, mixed viewpoints, mirrored flip, structural deformation, art style shift, replaced background, color tone shift, text, watermark`

> 本技能要**保持**原图画风，故不把「原图画风残留」列为负面项；反之「画风跳变」「背景被替换」才是需要排除的失败。

是否输出按 `CFG` 判定：

| `CFG` | 处理 |
|---|---|
| `= 1`（Turbo / 蒸馏变体） | 负面词两节**整节省略**；排除项改写为正向排除句追加到每条提示词末尾 |
| `> 1` | 正常输出两节（全局一套，不逐条重复） |

## 6. 模型与参数

| 需求特征 | 推荐模型 | 理由 |
|---|---|---|
| 参考图编辑、局部一致性 | qwen-image-2.1 | 参考图编辑原生，局部一致性更强 |
| 结构稳定、几何一致 | FLUX.2-klein | 多主体与结构稳定 |
| 中文描述、姿态语义 | qwen-image-2.1 | 中文语义理解 |

| 项 | 取值 |
|---|---|
| `denoise`（i2i） | `0.45~0.65`：偏低以锁身份与姿态，过高会把视角变化放大成主体变形 |
| 分辨率 | 1024 起，须为 16 的倍数；各视角保持一致尺寸 |
| CFG | Turbo / 蒸馏 `1.0`；标准版 / Base `2.5~4.0` |

> - `denoise` 区间为经验起始值，按实际平台调整；变体必须注明；Turbo / 蒸馏变体 CFG 恒为 1。
> - 扩散模型对「同一状态换视角」的三维一致性能力有限：强一致需求建议配合 IP-Adapter / ControlNet 等外部参考组件，并在 tips 说明文本约束不能保证几何精确。

## 8. 边界与自检

以下写入 `tips`：

1. 无参考图时明确说明本技能不适用，不臆测主体状态。
2. 提示词文本无法保证几何级三维一致；强一致需求建议外部参考组件。
3. 多视角不要写成多格画面或设定表，每条提示词单独出图。
4. 用户指定的状态与参考图冲突时，在 tips 提示冲突并按参考图优先。

输出前自检：

1. 参考图前提成立，视角集与用户要求一致，每条只含一组方位 + 俯仰措辞，未写朝向词
2. 四条结构齐全、顺序正确；状态保持项按 §2 可见性原则裁剪，不可见特征未写入；无「保留相机视角 / 保持构图不变」类措辞；场景与背景延续原图，未写成纯色 / 简洁背景
3. 主体锚点、服饰、姿态在都可见的视角条目里用词一致；全局约束未逐条重复
4. 段内逗号、段间分号，中英一一对应；负面词按 `CFG` 判定；参数与 §6 一致
