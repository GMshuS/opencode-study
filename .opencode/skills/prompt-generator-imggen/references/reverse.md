# reverse 图片反推结构

## 1. 输入前提

只处理宿主在会话中可见的图片。图片未成功传入或当前模型不支持视觉输入时，不臆测画面内容，告知用户改用文字描述或换用支持视觉的模型。图片中的文字记入主体类，文案原样保留。

## 2. 观察与取舍

观察结果按 **风格 → 主体 → 场景** 组织，类内从整体到细节；只写颜色、形态、光线方向与质感、景别与视角等可观察属性，具体词由本次观察决定，不预设候选清单。

- 不猜测身份、品牌、情绪、故事背景。
- 看不清或不确定的项标「未识别」，整段省略并在「💡 小贴士」说明；不硬猜、不补默认值凑格式，也不因维度缺失推测补全。
- 推断性内容（如具体焦段）加「（估）」并在「💡 小贴士」提示。
- 反推以可观察内容为上限，不适用主动扩写。

## 3. 两版输出

填「📝 反推结果」：原始反推（仅可观察特征的中英提示词）、调整后（按用户要求修改后的最终正向提示词）、变更项（改了哪一类、改前 → 改后）。无调整要求时两版相同，变更项记 `—`。

## 4. 按用户要求调整

- 调整对象是上一步产出的提示词文本，不是对原图做编辑。
- 只改被点名的类或其字段，其余保持原样；不因调整而顺手扩写其它类。
- 用户提出替换某类内容时按文本修改处理；若明确要求改动原图本身，说明超出反推范围并在「💡 小贴士」提示。

## 5. 边界

反推是近似描述，无法 100% 复现原图；要精确复现请把原图作为参考素材（「💡 小贴士」必写）。
