# reverse 图片反推结构

## 1. 输入前提

- 只处理**宿主在会话中可见的图片**（用户直接贴图）。
- 不主动读取图片文件、不调用视觉识别工具。若只给了文件路径、图片未成功传入、或当前模型不支持视觉输入：
  **不臆测画面内容**，告知用户改用文字描述画面或换用支持视觉的模型（主文件 §5）。
- 图片中的文字属于「画面文字内容」，记入主体类；文案原样保留。

## 2. 观察 → 三类映射

按 **风格 → 主体 → 场景** 组织，顺序不可打乱，类内按「整体 → 细节」排列。

- **风格 style**
  - 画面类型 / 媒介：照片、插画、3D 渲染、海报版式、UI 等
  - 画风 / 美学：胶片、赛璐璐、水墨、极简等；配色、色调、氛围
- **主体 subject**：类别与数量、形貌、配色、服饰、主体材质、动作姿态、表情、画面文字
- **场景 scene**
  - 环境 + 光线：背景、时间 / 天气、光源方向与质感、色调
  - 镜头 + 构图：景别、视角、焦距 / 景深、构图、画面比例

### 只写可观察特征

- 写「看得到什么」：`银白色短发`、`侧逆光`、`浅景深`、`50mm 视角（估）`。
- 不猜测身份、品牌、情绪、故事背景；不写画质词（高清 / 8K / masterpiece）与抽象评价词（很美 / 高级感）。
- 看不清或不确定的项标「未识别」，在 tips 说明；**不硬猜、不补默认值凑格式**。
- 推断性内容（如具体焦段）加「（估）」并在 tips 提示。

## 3. 输出

- 三类顺序与字段以本文档 §2 为准；段内逗号、段间分号、中英对应与排版按主文件 §4.1。
- 未识别的类在「📝 拆解明细」中记 `—`，提示词正文省略该段连同其分号。
- 填主文件 §3 的「📝 反推结果」小节，给两版：
  - **原始反推**：仅可观察特征的中英提示词
  - **调整后**：按用户要求修改后的中英提示词（即最终 `{{positive_cn}}` / `{{positive_en}}`）
  - **变更项**：列出被改了哪一类、改前 → 改后
- 无调整要求时，两版相同，变更项记 `—`。
- 同时填「📝 拆解明细」三行（风格 / 主体 / 场景）。

## 4. 按用户要求调整

- 调整对象是**上一步产出的提示词文本**，产出一份新的提示词，不是对原图做编辑。
- 只改被点名的类或其字段，其余保持原样；不因调整而顺手扩写其它类。
- 用户说「把背景换成夜景」「风格改成水彩」时按文本修改处理；若明确要求改动原图本身，说明超出反推范围并在 tips 提示。
- 调整后仍遵守主文件 §4.1 的分号分层与「一个属性只写一次」。

## 5. 边界与提示

- 反推是**近似描述**，无法 100% 复现原图；要精确复现请把原图作为参考素材（tips 必写）。
- 默认不输出「⚙️ 参数建议」与「❌ 负面提示词」两节；用户要求「给个能复现的模型」时，按风格层的画面类型命中主文件 §2.3。
- 负面词按主文件 §2.4 处理：默认不输出；用户要求模型 / 参数建议且 `{{cfg_scale}} > 1` 时只用通用兜底与用户排除项。
