# 图生图 / 局部重绘：提示词生成规范

## 0. 定位

本文档只规定「如何思考」与「什么算合格」；所有措辞由模型按本次输入生成，文中词句只用于说明结构或标明反例，不得当作模板或默认词。不套模板、不做填空、不受固定情形枚举限制。

## 1. 输入资产清点

先清点本次提供了哪些图、各自扮演什么角色，并让提示词中的指代全程一致。

| 角色 | 含义 |
|---|---|
| 基底图 | 改动落在其上、大部分画面内容需要被保留的图 |
| 素材图 | 只贡献某个元素 / 风格 / 配色，本身不作为画面主体保留 |
| 融合输入 | 没有单一基底，多张图的内容共同构成新画面 |

- 只有一张基底图时可用「原图」；两张及以上时禁止无指向的「原图」「周围画面」，须写明是哪张图、什么角色、从哪张图取什么。
- 跨图引用写成可区分的形式，如「参考图1（基底）」「参考图2（素材）」；每个指代都须唯一可解析。
- 角色无法判断时在「💡 小贴士」说明所取理解，影响结果时追问一句；不臆造角色。

## 2. 模式判定看「保留机制」

| 判据 | 模式 | 保留由谁保证 |
|---|---|---|
| 以基底图为起点，改动作用于整幅属性 | `img2img` | 主要由 denoise 控制 |
| 改动限于可定位局部，区域外需保持 | `inpaint` | 由蒙版保证 |
| 内容来自两张及以上图，需组合 / 移植元素 | 参考图驱动编辑 / 多图融合 | 平台多图输入 + 可能的蒙版 |

- 三者是「作用域 × 素材数量」的组合，不是互斥标签；按平台实际能力选 `inpaint` 或「`img2img` + 蒙版」。
- 动词（换成 / 改为 / 去掉 / 参考图）只作线索；判定依据是「什么内容必须保留、靠什么机制保留」。
- 背景 / 天空等大范围替换未指定蒙版时按整幅变换处理；判定歧义且影响结果时在「💡 小贴士」写明所取理解与替代路径。
- 模式名不反过来限制提示词：段数、段落职责、措辞一律由本次改动决定。

## 3. 正向提示词的生成

### 3.1 每次重新推一遍

1. 本次要改什么？从用户描述抽取变更目标，不编造用户没提出的改动。
2. 改完之后，哪些内容必须与哪张图保持一致？据此决定是否写基准段、锚定到哪张图、锚定哪些属性。
3. 改动会波及哪些相邻属性？据此决定是否写衔接段、写哪几个方面。
4. 按「基准 → 变更 → 衔接」组织；不需要的段整段省略（连同其分号）。

### 3.2 段落只定义职责

| 段 | 要回答的问题 | 内容来源 |
|---|---|---|
| 基准 | 哪些属性以哪张图为基准保持不变 | 由变更项反推，只写本次真正需要守住的属性 |
| 变更 | 改成什么样、内容取自哪里 | 用户原话 + 必要的可观察细化 |
| 衔接 | 新内容与相邻内容在哪些方面要接得上 | 由改动位置与类型按需选取 |

- 段数、段序不固定；不把「构图 / 光影 / 色调」当默认三件套，与改动无关的锚点是噪声。
- 不描述基底图已有的外观细节、不编造图中没有的元素；主体只写类别词或角色指代。
- 不写「其余元素全部不变」这类冗余指令，也不用 `Mask area:` 之类标签。

### 3.3 编辑特有的取舍

允许为让改动成立而补齐可观察描述（光影、透视、比例、材质表现、细节层次等），措辞由模型生成；具体材质 / 物件 / 风格名不得当作默认输出。

### 3.4 失效模式（反例，仅用于自检）

| 情形 | 不合格表现 | 原因 |
|---|---|---|
| 用户只说「提升质感」 | 出现某种具体材质名称 | 擅自具体化，把示例当默认词 |
| 两张参考图做局部替换 | 出现无指向的「原图」指代，或锚点属性与改动无关 | 指代不唯一，锚点变成噪声 |
| 两图融合 | 因没有对应情形而套用最接近的模板或拒答 | 用枚举代替理解 |
| 用户描述简略 | 只做直译、不补齐必要维度 | 未执行默认扩写 |
| 任何需求 | 段落数由模式名决定、句式与旧模板雷同 | 填空题式输出 |

> 这些只用于自检，不是替换表。

## 4. denoise 联动（仅单基底图 `img2img` 成立）

`img2img` 下 denoise 才真正决定保留程度：

| denoise | 文本层取舍 |
|---|---|
| 低（约 <0.55） | 保留已由参数保证，基准类约束可极简或省略，正文聚焦变更项 |
| 中（约 0.55~0.7） | 写一条与本次改动相关的基准约束 |
| 高（约 >0.7） | 文本约束效果有限，不要靠加重措辞补偿；在「💡 小贴士」提示降低 denoise 或改用带蒙版的局部编辑 |

> `inpaint` 的基线 denoise 较高（蒙版区域需充分重绘），区域外由蒙版保证，不套用上表，也不因 denoise 较高而弱化文本或额外告警。

## 5. 负面词风险维度

仅作启发，按需组合、不设取值枚举、不原样照抄：身份 / 结构漂移、原风格残留、材质或光照割裂、边缘错位与拼接痕迹、修改区域外被改动、局部畸变、多余主体、人物五官与手指异常。

## 6. 输出

- 参数建议中 `denoise` 必填；局部重绘用其专属区间。
- 多图 / 跨图场景在「💡 小贴士」写明图片绑定、蒙版归属与平台能力前提。
