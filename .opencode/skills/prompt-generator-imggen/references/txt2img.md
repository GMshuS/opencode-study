# txt2img 生成结构

## 1. 组织方式

正向提示词按 **风格 → 主体 → 场景** 组织，类内从整体到细节。三类是可展开的维度，不是必须填满的槽位，也不是候选词清单；具体包含哪些属性由用户描述与画面逻辑决定。

- 材质归属：主体自身材质归主体类，环境材质归场景类，同一材质只写一次。
- 文字里写明的风格 / 配色 / 氛围写入风格类；风格层的画面类型可用于命中模型推荐。

## 2. 分支特有约束

- 不硬加与画面无关的动态。
- 影响结果的信息缺口在「💡 小贴士」说明所取理解，或追问一句。

## 3. 版式文字场景（MOSS-Image SFT）

额外产出 `layout`：画布比例 + 元素表（内容 / bbox / 样式），填入「🧩 版式布局」小节。

- 文案原样保留，不改写、不翻译、不截断；文案内自带标点不算结构分隔符。
- 版式文字是画面内容，不是提示词修饰词，不参与裁剪。

## 4. 负面词风险维度

仅作启发，按需组合、不设取值枚举、不原样照抄：人物形貌与肢体、结构与比例、线条与笔触、材质与反光、文字与版式、渲染几何、风格串味、时代或物件穿越感、多余主体。

## 5. 输出

- 正向提示词只描述目标画面，不写以图片为基准的约束。
- 参数建议中 `denoise` 一栏写 `—`。
