## 1. 定位与边界

产出**单张静态多格画面**的提示词：漫画页、多格漫画、动作分镜图、分格叙事插画。按格组织画面内容与文字元素，并保证跨格一致。

本技能只做文本编排：不读取图片文件，参考图由出图平台接收。不处理视频分镜、时间轴与逐帧时序，提示词里**不写秒级时间戳**。

> 与单幅画面的区别：不是「一个画面写三类」，而是「N 个画面 × 内容 + 一个全局约束层 + 一个布局层」。

## 2. 输入判定

| 维度 | 取值 |
|---|---|
| 画面类型 | 漫画页（含对话框 / 拟声词）/ 动作分镜图（连续动作分格）/ 一般分格叙事 |
| 格数与排列 | 用户给定则遵从；未给定按 2~4 格、横向或网格排列，并在 tips 说明 |
| 参考图 | 有则作为角色 / 画风参考，不描述图中没有的元素；无则纯文字生成 |
| 文字元素 | 台词、旁白、拟声词、标题；文案原样保留，不改写不翻译 |

## 3. 三层结构

### 3.1 全局层（只声明一次，不逐格重复）

- 画风 / 媒介：漫画、赛璐璐、网点、黑白 / 彩色
- 角色外观锚点：身份、发色服饰、体型比例（跨格必须一致）
- 光影色调、整体氛围
- 阅读顺序：从左到右 / 从上到下（中文漫画可注明从右到左）

### 3.2 布局层

- 格数、排列方式、格大小差异（主格大、辅格小）
- 分割线、留白、画面不重叠
- 文字元素位置：对话框、旁白框、拟声词
- 需要精确定位时产 `bbox` 表（见 §7）

### 3.3 分格层（每格一条）

| 字段 | 内容 |
|---|---|
| 格号 | 按阅读顺序编号 |
| 主体与动作 | 该格可见的主体、动作、表情 |
| 景别 / 镜头 | 全景、中景、特写、俯视等 |
| 场景 / 光线 | 该格的环境与光照，需与全局层一致 |
| 文字 | 台词 / 拟声词 / 旁白，原样保留 |

## 4. 组装规则

1. 正向提示词顺序：**全局层 → 布局层 → 分格层（按格号）**。全局层只在开头出现一次。
2. 段内用逗号，段间用分号（`；` / `; `）；中英分号数量相等、一一对应、单句不混排。
3. 分格要点写成短句，如 `第一格：全景，街道，两人对峙`；**不要**把分格表的 bbox / 台词全部复述进提示词。
4. 段间分号是连接符，句尾不加分号；格数省略时连同分号一起省略。
5. 简明扼要，用词语或短语；不堆同义词，不写画质词与抽象评价词。
6. 强调靠语序前置，不用 `(word:1.2)` 权重语法。
7. 全局一致性约束独立成句追加在末尾：`全程角色外观、画风、光影统一，各格之间不串格` / `keep character appearance, art style and lighting consistent across all panels, no panel bleeding`。

## 5. 负面词（直接取用）

- 中文：`跨格角色不一致，分格融合，画面重叠，画风跳变，光影断层，乱码文字，对话框溢出，文字错行，多余格子，水印`
- English: `inconsistent character across panels, merged panels, overlapping frames, style shift, lighting discontinuity, garbled text, speech bubble overflow, misaligned text, extra panels, watermark`

是否输出按 `CFG` 判定：

| `CFG` | 处理 |
|---|---|
| `= 1`（Turbo / 蒸馏变体） | 负面词两节**整节省略**；用户明确排除的元素改写为正向排除句追加到提示词末尾 |
| `> 1` | 正常输出两节 |

> 漫画页本身需要文字，负面词中「乱码文字 / 对话框溢出」指排错，不是禁止文字。

## 6. 模型与参数（2026-10 快照）

| 需求特征 | 推荐模型 | 理由 |
|---|---|---|
| 需要 bbox 精确定位、成段文字、对话框排版 | MOSS-Image SFT | bbox 布局可控，约 4K token（仅 t2i） |
| 中文台词 / 国风漫画 / 中文叙事 | qwen-image-2.1 | 中文语义与文字渲染 |
| 复杂构图、多主体、格间结构稳定 | FLUX.2-klein | 构图稳定，长提示词承载力强 |
| 二次元 / 赛璐璐 / 网点漫画 | Z-Image-Turbo | 二次元画风调度稳定 |

> - 变体必须注明；Turbo / 蒸馏变体 CFG 恒为 1。
> - 分辨率须为 16 的倍数；MOSS 任意比例。格数越多越需要横向空间，优先 3:2 / 16:9。
> - 官方可查：FLUX.2 `max_sequence_length` 512、MOSS 约 4K token；其余为经验值，以实际平台为准。

## 7. 输出格式

```markdown
## 📚 多格画面提示词结果
画面类型：{{panel_type}}｜格数：{{panel_count}}｜阅读顺序：{{reading_order}}
✅ 推荐模型：{{model}}｜备选：{{alternative}}

---
### ✅ 正向提示词（中文）
{{positive_cn}}

### ✅ Positive Prompt (English)
{{positive_en}}

---
### ❌ 负面提示词（中文）
{{negative_cn}}

### ❌ Negative Prompt (English)
{{negative_en}}

---
### 🧩 分格表
| 格号 | 主体 / 动作 | 景别 / 镜头 | 场景 / 光线 | 文字 | bbox |
|---|---|---|---|---|---|
| {{id}} | {{content}} | {{shot}} | {{scene}} | {{text}} | {{bbox}} |

### ⚙️ 参数建议
- 模型变体：{{model_variant}}
- 分辨率比例：{{resolution}}
- CFG：{{cfg}}
- 采样步数：{{steps}}

### 💡 小贴士
{{tips}}
```

> `bbox` 列仅在需要精确定位时填写，否则记 `—`；`CFG=1` 时负面词两节整节省略。

## 8. 边界与自检

以下写入 `tips`：

1. 用户未给格数 / 排列时按 §2 取默认并说明。
2. 文字元素超过模型承载能力时，在 tips 提示「成段文字优先 MOSS-Image SFT」。
3. 跨格角色一致性是难点：必要时建议降低格数或提供角色参考图。
4. 本技能不产出视频时序分镜，也不写秒级时间戳。

输出前自检：

1. 画面类型、格数、阅读顺序、文字元素判定齐全
2. 三层结构齐全，全局层只声明一次，分格按格号顺序
3. 段内逗号、段间分号，中英一一对应；全局一致性约束已追加
4. 负面词按 `CFG` 判定；参数与 §6 一致，已注明变体；分格表已填
